## Example media

The interview example contains a fictional dialogue generated for this repository with eSpeak NG, two synthesized knocks and a measured transcript. The renderer example reuses the first second of this recording. Its HTML and Blender scenes are original examples. The rolling-wheel reference take is a new synthetic reading of the public starter script with Kokoro v1.0. No model weights ship with these recordings. [Interview source](examples/studio-session/material/make-recording.py) · [Voice fixture](docs/cue-direction.md)

The history film's reference FLAC is an original Kokoro reading of its script. Its accompanying timing file records measured sample boundaries. The history example includes brief attributed passages with links and source locators in its selection file. Its proposed artwork is an original instructional diagram.
